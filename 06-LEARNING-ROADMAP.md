# 📅 Your 12-Week Coding Learning Roadmap

## Overview

This roadmap is designed for a complete beginner with:
- 1-2 hours daily study
- 5-6 days per week commitment
- Focus on Python first, then web development

---

## WEEK 1-2: Foundation & Setup

### Goals
- [ ] Install all tools (Git, VS Code, Python)
- [ ] Understand GitHub basics
- [ ] Write first Python programs
- [ ] Understand variables and data types

### Daily Tasks
**Mon-Wed:**
- Install tools (2-3 hours)
- Watch Git basics tutorial (1 hour)
- Create first GitHub repo (30 mins)

**Thu-Fri:**
- Python variables tutorial (1.5 hours)
- Practice: Create 5 small programs (1 hour)
- Commit to GitHub (30 mins)

**Sat-Sun:**
- Review and practice (1 hour)
- Read Python documentation (1 hour)
- Daily commit challenge (30 mins)

### Projects
✅ Hello World program
✅ Simple variable practice scripts
✅ Create GitHub profile README

### Resources
- freeCodeCamp Python for Beginners (first 2 hours)
- Traversy Media Git & GitHub Crash Course
- Official Python documentation

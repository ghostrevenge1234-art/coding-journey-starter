## Learning Roadmap Path

```
Week 1-2: Fundamentals
├─ Variables & data types
├─ Operators & basic math
├─ Input/output
└─ Git & GitHub basics

Week 3-4: Control Flow
├─ Conditionals (if/else)
├─ Loops (for/while)
└─ Practice exercises

Week 5-6: Data Structures
├─ Lists & arrays
├─ Dictionaries & sets
└─ String manipulation

Week 7-8: Functions & Modules
├─ Function definition
├─ Parameters & returns
├─ Libraries & imports
└─ First small projects

Week 9-10: Web Basics
├─ HTML fundamentals
├─ CSS styling
└─ JavaScript intro

Week 11-12: Integration
├─ Build a small website
├─ Connect frontend & backend
└─ Deploy project to GitHub Pages
```

## Time Investment

**Recommended Schedule:**
- 1-2 hours per day
- 5-6 days per week
- 12-16 weeks to basics competency
- 1-2 years to intermediate level
